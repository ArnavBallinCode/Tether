# Tether: Autonomous Revenue Operations Layer

Tether finds revenue that's slipping away and wins it back.

Instead of generic dunning emails or blind retries, Tether acts as an autonomous agent that:
1. Detects revenue at risk
2. Diagnoses the root cause using customer behavioral history
3. Determines the optimal intervention
4. Executes a bounded recovery workflow
5. Measures the resulting recovery

## Running the Demo

1. Install dependencies: `pip install -r requirements.txt`
2. Run the API and UI: `python -m tether.api.main`
3. Open `http://localhost:8000` to see the Executive Dashboard and Recovery Simulator.
